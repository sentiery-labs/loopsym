## 검증 명령 모음 (Codex 용)

```bash
# 1, 7: wheel 검증 (빌드 포함)
python tools/check_wheel.py

# 2, 5: CLI 분기 (브라우저 안 열림)
python -m pytest tests/test_cli.py -q

# 3: 뷰어 실행 경로 헤드리스 (node + npm install 필요)
python -m pytest tests/test_pyodide_smoke.py -q

# 전체 회귀
python -m pytest tests/ -q

# 실브라우저 육안 (3, 4, 8):
loopsym                       # PI 데모 → ▶ 실행 → ref/y 확인
#  - 네트워크 차단 후 실행 → 상태줄 복구 명령 확인
#  - 창 폭 1024px 에서 4패널 겹침 없는지 확인
```
