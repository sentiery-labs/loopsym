# UX 리뷰(ux_review_codex.md) 판정 및 대응 계획

- 판정 일자: 2026-07-19 (기준 커밋 `799fc7c` + 이후 HEAD)
- 판정자: Claude (충박사 사전 결정 반영)
- 사실 확인: 리뷰의 재현 주장을 저장소에서 전수 대조 — **전부 사실과 일치**
  (0.1.0 wheel 에 `__main__`/예제/entry point 없음, `[project.urls]` 부재,
  README 빠른 시작이 체크아웃+`matplotlib` 가정, CI 는 editable 설치만 검사,
  CLI 의 빈 `Diagram()` 임베드가 뷰어 `demoModel()` 폴백을 덮음 — 각 확인).

## 총평

**리뷰의 핵심 프레임("좋은 뷰어는 있으나 골든 패스가 없다")에 동의한다.**
모든 발견에 재현 절차와 파일:라인 근거가 붙어 있고, 검증 기록의 항목별
결과가 저장소 상태와 일치한다. 반박할 발견은 없으며, 판정은 수용 범위와
릴리스 배치(0.1.1 vs 백로그)의 문제다.

특히 뼈아픈 지적: **"배포와 저장소가 다른데 CI 가 그 차이를 못 본다"** —
이번 세션에서 CLI/예제가 빠르게 쌓이는 동안 wheel 검증이 없어 생긴 구조적
공백이다. 차단 항목 5(wheel 설치 CI)가 재발 방지의 근본책이며 **필수**다.

## 발견별 판정

### P0. PyPI 설치 후 실행할 수 있는 공식 첫 경험이 없다 → **수용 (확정)**

근거: 재현 사실 그대로. 0.1.0 은 CLI 이전 시점의 스냅샷이라 wheel 에
`__main__.py`/entry point/예제가 없고, README 는 체크아웃 경로만 안내한다.
CLI 자체는 HEAD 에 이미 있으므로(`eb51060`, `3edef33`) 해소의 본체는
**0.1.1 버전 bump + 재배포**이고, 잔여 작업은 `[project.urls]`, 최소 예제
JSON 패키지 데이터, README 골든 패스다. 전부 0.1.1 차단 항목으로 수용.

### P1. 소스 체크아웃 빠른 시작이 깨끗한 환경에서 실패 → **동의**

근거: `examples` extra 는 선언돼 있으나 README 가 안내하지 않는다 — 문서
결함이 맞다. 대응(0.1.1): ① README 빠른 시작을 "PyPI 3단계"(설치 →
`loopsym` → 실행)로 교체, 소스 개발 절을 분리하고 `pip install -e
".[examples]"` 명시 ② README 의 두 번째 파이썬 예시는 `render_html()`
반환 경로를 출력하고 `webbrowser.open` 한 줄 추가(성공이 보이게).

### P1. 새 CLI 의 기본 화면이 첫 성공을 돕지 않는다 → **수용 (확정, 세부 결정 반영)**

근거: 재현 사실 그대로 — 빈 임베드가 데모 폴백보다 우선하므로 코드 주석
("초기 모델 버튼으로 데모 로드 가능")도 현재 빈 캔버스에서는 거짓이다.

확정된 설계 (충박사 결정):
- **인자 없는 `loopsym` = PI 데모** (연결 완료 + Scope, 실행만 누르면 됨)
- **`--blank` = 빈 캔버스**, `--example <이름>` 추가 (차단 항목 2)
- **데모 화면에 "새로 시작" 버튼** — 빈 캔버스로 전환하는 명시적 출구
- "초기 모델" 버튼은 "되돌리기"로 개명 (현재 의미와 일치)

부분수용: 뷰어 내 "예제 메뉴"(PI/진자/이산 PI 드롭다운)는 0.1.1 범위에서
제외하고 백로그 — `--example` CLI 로 같은 요구를 먼저 충족한다.
동의: 데모 정본 단일화 — 뷰어 JS `demoModel()`/파이썬 예제/패키지 JSON 이
어긋나지 않게 **패키지 데이터 JSON 1개를 정본**으로 삼는다.

### P1. 설치 방식·뷰어 모드·오프라인 경로가 한 문서에 섞임 → **부분수용**

동의하는 부분(0.1.1 포함):
- README 최상단 PyPI 3단계 골든 패스 + 첫 실행 CDN 조건 명시 (차단 항목 3)
- **명백한 오류 수정**: 서버 절의 `pip install -e ".[server]"` 를 PyPI 형
  (`pip install "loopsym[server]"`)과 병기, 오프라인 안내를 실제 동작
  (file:// 는 CDN 전용 → 오프라인은 서버 모드/http.server 필수)에 맞게 정정.
  vendored 사본이 http 서빙에서만 유효하다는 조건 명시.

백로그로 미루는 부분: README 전체를 5개 절로 재구성, `loopsym serve`
단일 프로세스 통합(HTTP+WS+브라우저). 방향은 동의하나 0.1.1 은 "골든 패스
성립 + 거짓 문서 제거"까지가 적정 범위다.

### P2. 예제 카탈로그 부재 → **부분수용**

0.1.1 포함(문서만, 저비용): `examples/README.md` — ex1~ex10 난이도/예상
시간/의존성(extra)/생성물/다음 예제 표. 루트 README 의 예제 표를 ex10 까지
갱신. wheel 의 최소 예제 JSON(PI/진자/이산 PI)은 차단 항목 4에서 이미 확정.

백로그: README 스크린샷(호스팅·유지 비용 — 뷰어가 안정된 뒤 1장),
`course/README.md` 의 Jupyter/pytest 설치 명령 한 줄은 0.1.1 에 끼워 넣는다
(이번 세션에서 실제로 걸렸던 문제).

### P2. 작은 화면·키보드 접근성 → **부분수용 (확정)**

충박사 결정대로: **0.1.1 은 README 에 "데스크톱 전용, 최소 폭 1024px"
명시로 종결.** 대상 사용자(강의실 데스크톱/노트북)와 일치하므로 릴리스
차단으로 두지 않는 판단에 동의한다. 나머지는 백로그 등록:
- 900px 이하 드로어 레이아웃 (모바일 지원을 결정하는 경우)
- 상태줄 `role="status"`/`aria-live`, 블록 focus/키보드 선택·삭제 경로
- PyFunction 대화상자 `min-width: 560px` 완화
