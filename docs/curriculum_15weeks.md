## 파트 1 — 블록과 신호 (파이썬: 기초·클래스)

**1주. 시뮬레이션이란 무엇인가**
- 목표: 신호(시간의 함수)와 블록(신호 변환기) 개념. 파이썬 실행 환경.
- 이론: Simulink 데모(또는 blocksim 뷰어)로 폐루프 감상 — "이걸 15주 뒤에 직접 만든다".
- 실습: 파이썬 기초 1 (변수, 함수, 리스트). `step(t)`, `sine(t)` 함수 만들기.
- 과제: 함수 3개(step/ramp/sine)를 t 리스트에 적용해 matplotlib 플롯.
- 평가: 채점기 — 함수값 스팟 체크.

**2주. 클래스로 블록 만들기**
- 목표: 클래스/인스턴스/메서드. "블록 = 상태 + 동작을 가진 객체".
- 이론: 왜 함수가 아니라 클래스인가 (파라미터를 품는다: Gain 의 k).
- 실습: `Block` 베이스 → `Gain`, `Constant` 상속. `output(t, u)` 규약.
- 과제: `Saturation`, `Offset` 블록 구현.
- 평가: 채점기 — 임의 입력에 대한 출력 일치.

**3주. 상속과 인터페이스 규약**
- 목표: 상속·오버라이드·덕타이핑. n_in/n_out 포트 개념.
- 이론: "모든 블록이 같은 규약을 따르면 엔진은 블록 종류를 몰라도 된다."
- 실습: `Sum(signs)`, `Product(ops)` — 문자열 파라미터로 포트 수 결정.
- 과제: `PyFunction(expr)` — eval 로 식 블록 만들기 (MATLAB Function 대응).
- 평가: 채점기 + 코드리뷰 1회 (규약 준수).

## 파트 2 — 연결과 실행 순서 (파이썬: 자료구조·알고리즘)

**4주. 다이어그램 = 그래프**
- 목표: 딕셔너리·튜플. 와이어를 자료구조로 표현.
- 이론: 그래프(노드/간선), Port 튜플, "입력 포트당 드라이버 하나" 불변식.
- 실습: `Diagram.add/connect` + 연결 검증(미연결/중복 에러).
- 과제: 잘못된 연결 4종을 잡아내는 검증 코드.
- 평가: 채점기 — 에러 케이스 전부 발생시켜야 PASS.

**5주. 실행 순서 — 위상 정렬**
- 목표: 의존 그래프, Kahn 알고리즘.
- 이론: "Gain 은 입력이 먼저 계산되어야 한다" → 순서 제약 → 위상 정렬.
- 실습: `compile()` 구현, 개루프 체인 실행 (소스→게인→출력 손 계산 대조).
- 과제: 다이아몬드 연결(한 소스→두 경로→Sum) 실행 순서 검증.
- 평가: 채점기.

**6주. 피드백과 대수 루프**
- 목표: 순환 그래프의 문제. feedthrough 개념.
- 이론: Gain 끼리 고리 = 답이 없는 연립(대수 루프). 적분기는 왜 고리를 끊는가
  (출력이 '현재 입력'이 아니라 '과거의 누적'이므로).
- 실습: 대수 루프 검출 + 에러 메시지. `feedthrough=False` 특별 취급.
- 과제: 루프 있는/없는 모델 5개 판별.
- 평가: 채점기 + 중간 구술 (④~⑥ 개념).

## 파트 3 — 적분과 시간 (파이썬: numpy·수치해석)

**7주. 상태와 오일러 적분**
- 목표: 미분방정식 → 코드. 상태(state) 개념.
- 이론: dx/dt=u 를 x += dt·u 로. 1차 시스템 손 풀이와 비교.
- 실습: `Integrator` 블록 + 오일러 솔버. RC 회로(1차) 시뮬레이션.
- 과제: dt 를 바꿔가며 오차 측정 → 오차가 dt 에 비례함을 그래프로.
- 평가: 채점기 + 오차 그래프 제출.

**8주. RK4 와 수치 안정성**
- 목표: 고차 적분법. "왜 오일러는 발산하는가".
- 이론: RK4 유도(개념 수준), 안정 영역 개념.
- 실습: 솔버를 RK4 로 교체 (오차 1e-11 체험). 진동계에서 오일러 발산 재현.
- 과제: e⁻ᵗ 문제로 오일러/RK4 오차 비교표.
- 평가: 채점기 — RK4 정확도 기준(1e-9) 통과.

**9주. 폐루프 제어 — P, PI**
- 목표: 지금까지 만든 전부로 제어 루프를 닫는다.
- 이론: 오차 피드백, P 의 정상상태 오차, I 가 오차를 없애는 이유.
- 실습: ref→err→PI→plant→scope (ex1 재현). 게인 튜닝 체험.
- 과제: 진자(비선형, PyFunction)에 PD → 정상상태 오차 관찰 → I 추가 (ex2).
- 평가: 채점기(수렴 판정) + 튜닝 리포트 1쪽.

## 파트 4 — 구조화 (파이썬: 재귀·JSON·직렬화)

**10주. 서브시스템과 재귀**
- 목표: 계층 구조, 재귀 함수.
- 이론: Inport/Outport 경계, flatten 알고리즘 (재귀로 펼치기).
- 실습: PI 를 서브시스템으로 묶기 (ex3). 뷰어에서 묶기/풀기 체험.
- 과제: 2단 중첩 서브시스템이 평면 모델과 같은 결과인지 테스트 작성.
- 평가: 채점기.

**11주. 저장과 마스크 — 모델의 데이터화**
- 목표: JSON 직렬화, 문자열 치환 패턴.
- 이론: "다이어그램도 데이터다" — save/load, 마스크 파라미터($Kp).
- 실습: save_json/load_json 구현·활용, 마스크 PI 서브시스템 3개를 게인만 바꿔 재사용.
- 과제: 자기 모델을 JSON 으로 제출 → 채점기가 load 해서 실행 검증.
- 평가: 채점기.

## 파트 5 — 이산 시간 (PX4 로 가는 다리)

**12주. 샘플링과 이산 블록**
- 목표: 연속 vs 이산. sample_time, ZOH.
- 이론: 실제 컨트롤러(PX4)는 주기적으로 도는 프로그램이다. z⁻¹ 소개.
- 실습: UnitDelay·DiscreteIntegrator 구현, 계단 응답으로 지연 확인.
- 과제: 이산 PI vs 연속 PI (ex4 재현), Ts 를 키워 성능 저하 관찰.
- 평가: 채점기 + Ts 영향 리포트.

**13주. 이산 제어기 설계**
- 목표: 연속 설계 → 이산 구현의 실무 감각.
- 이론: 전진 오일러 이산화, 샘플링이 만드는 위상 지연, 안정성 한계.
- 실습: DiscreteTransferFunction 으로 필터 붙은 D 항 구현 → 이산 PID 완성.
- 과제: 주어진 plant 에 사양(오버슈트<10%, 정착<3s) 만족하는 이산 PID 튜닝.
- 평가: 채점기(사양 자동 판정) — 이 과제가 사실상 기말 예행.

## 파트 6 — 종합 프로젝트

**14주. 쿼드로터 1축 자세 제어**
- 목표: 배운 전부의 종합. 실제 드론 구조와의 연결.
- 이론: 쿼드로터 1축 동역학(J·θ̈=τ), PX4 rate→attitude 캐스케이드 구조 소개.
- 실습: 1축 plant(PyFunction+적분기 2개) + 이산 rate 제어기 + 외곽 각도 루프.
- 과제(팀): 캐스케이드 튜닝 + 외란(돌풍 스텝) 리젝션.
- 평가: 채점기 + 팀 발표 준비.

**15주. 프로젝트 발표 + 다음 단계**
- 목표: 자기 모델을 설명하는 능력. 심화 과정 연결.
- 실습: 팀 발표 (다이어그램 화면 공유 + 파형 해설 + 코드 하이라이트).
- 데모: 강사가 같은 다이어그램을 실기체(Bebop 2/표준기체)로 — "다음 학기 예고"
  (P4 실기체 모듈 = 심화 과정 상품).
- 평가: 프로젝트 60% (채점기 40 + 발표 20), 주차 과제 40%.
