## 전반 — 파트 1~3: 엔진을 바닥부터 (파이썬 수업 트랙)

### 파트 1 — 블록과 신호 (파이썬: 기초·클래스)

**1주. 시뮬레이션이란 무엇인가**
- 목표: 신호(시간의 함수)와 블록(신호 변환기) 개념. 파이썬 실행 환경.
- 이론: blocksim 뷰어로 완성형 폐루프(드론 호버) 감상 — "전반 7주에 이 엔진의
  심장을 직접 만들고, 후반 8주에 이걸로 드론을 날린다".
- 실습: 파이썬 기초 1 (변수, 함수, 리스트). `step(t)`, `sine(t)` 함수 만들기.
- 과제: 함수 3개(step/ramp/sine)를 t 리스트에 적용해 matplotlib 플롯.
- 평가: 채점기 — 함수값 스팟 체크.

**2주. 클래스로 블록 만들기**
- 목표: 클래스/인스턴스/메서드. "블록 = 상태 + 동작을 가진 객체".
- 이론: 왜 함수가 아니라 클래스인가 (파라미터를 품는다: Gain 의 k).
- 실습: `Block` 베이스 → `Gain`, `Constant` 상속. `output(t, u)` 규약.
- 과제: `Saturation`, `Offset` 블록 구현.
- 평가: 채점기 — 임의 입력에 대한 출력 일치.

**3주. 상속과 인터페이스 규약**
- 목표: 상속·오버라이드·덕타이핑. n_in/n_out 포트 개념.
- 이론: "모든 블록이 같은 규약을 따르면 엔진은 블록 종류를 몰라도 된다."
- 실습: `Sum(signs)`, `Product(ops)` — 문자열 파라미터로 포트 수 결정.
- 과제: `PyFunction(expr)` — eval 로 식 블록 만들기 (MATLAB Function 대응).
- 평가: 채점기 + 코드리뷰 1회 (규약 준수).

### 파트 2 — 연결과 실행 순서 (파이썬: 자료구조·알고리즘)

**4주. 다이어그램 = 그래프, 실행 순서 = 위상 정렬**
- 목표: 딕셔너리·튜플로 와이어 표현. 의존 그래프와 Kahn 알고리즘.
- 이론: 그래프(노드/간선), "입력 포트당 드라이버 하나" 불변식,
  "Gain 은 입력이 먼저 계산되어야 한다" → 순서 제약 → 위상 정렬.
- 실습: `Diagram.add/connect` + 연결 검증(미연결/중복 에러) + `compile()`.
- 과제: 다이아몬드 연결(한 소스→두 경로→Sum) 실행 순서 검증 + 잘못된 연결 4종 검출.
- 평가: 채점기 — 에러 케이스 전부 발생시켜야 PASS.

**5주. 피드백과 대수 루프**
- 목표: 순환 그래프의 문제. feedthrough 개념.
- 이론: Gain 끼리 고리 = 답이 없는 연립(대수 루프). 적분기는 왜 고리를 끊는가
  (출력이 '현재 입력'이 아니라 '과거의 누적'이므로).
- 실습: 대수 루프 검출 + 에러 메시지. `feedthrough=False` 특별 취급.
- 과제: 루프 있는/없는 모델 5개 판별.
- 평가: 채점기 + 중간 구술 (2~5주 개념).

### 파트 3 — 적분과 시간 (파이썬: 수치해석)

**6주. 상태와 적분 — 오일러에서 RK4 로**
- 목표: 미분방정식 → 코드. 상태(state) 개념. 고차 적분법과 수치 안정성.
- 이론: dx/dt=u 를 x += dt·u 로. RK4 유도(개념 수준). "왜 오일러는 발산하는가".
- 실습: `Integrator` + 오일러 솔버 → RK4 교체 (오차 1e-11 체험).
  진동계에서 오일러 발산 재현.
- 과제: dt 를 바꿔가며 오차가 dt 에 비례함을 그래프로 + 오일러/RK4 오차 비교표.
- 평가: 채점기 — RK4 정확도 기준(1e-9) 통과.

**7주. 폐루프 완성 + ★브리지: 내 엔진 ↔ 진짜 blocksim★**
- 목표: 지금까지 만든 전부로 제어 루프를 닫고, 내 엔진이 "진짜"임을 증명한다.
- 이론: 오차 피드백, P 의 정상상태 오차, I 가 오차를 없애는 이유.
- 실습: ref→err→PI→plant→scope 를 **내 엔진으로** 실행 (ex1 재현).
  그 다음 같은 모델 JSON 을 정식 blocksim(뷰어)에서 실행 —
  **6자리까지 같은 숫자가 나오는 순간이 전반부의 졸업식이다.**
  뷰어 도구 익히기: 서브시스템 묶기/마스크/저장 (후반부의 작업 환경).
- 과제: 진자(비선형, PyFunction)에 PD → 정상상태 오차 관찰 → I 추가 (ex2).
  내 엔진 vs blocksim 교차 검증 리포트.
- 평가: 채점기(교차 검증 자동 대조) + 미니 엔진 코드 제출 (전반부 성적 확정).
- ※이후 주차는 정식 blocksim 플랫폼으로 진행. 서브시스템/flatten/JSON 직렬화의
  **구현**은 심화 선택과제(가산점)로 제공 — 초판 10~11주차 자료 재사용.

## 후반 — 파트 4~6: 팔레트를 열어 드론까지 (ARCHITECTURE §1 신호 사슬 순서)

주차 진행 = 팔레트를 하나씩 여는 것. 학기 초에 그린 다이어그램이 학기 말
(실기체)까지 같은 그림 — 센서/플랜트의 fidelity 파라미터만 올라간다 (§2 규약).

### 파트 4 — 플랜트와 제어 (Plant → Control → Allocation)

**8주. Plant 팔레트 — 6-DoF 쿼드로터**
- 목표: 13-상태 강체 동역학의 구조 이해. 개루프 불안정 체험.
- 이론: pos/vel/quat/omega, 추력과 토크, 왜 드론은 손을 놓으면 뒤집히는가.
- 실습: 6-DoF Quad 블록 + 모터 입력 상수 → 개루프 발산 관찰.
  fidelity 개념 소개 (오늘은 ideal — "이 드롭다운이 학기 말에 실기체가 된다").
- 과제: 호버 추력 손 계산 → 상수 입력으로 몇 초나 버티는지 실험 리포트.
- 평가: 채점기(모델 JSON 제출) + 리포트.

**9주. Control I — 샘플링과 Rate 제어**
- 목표: 이산 시간(실제 컨트롤러는 주기 프로그램), 각속도 PID.
- 이론: sample_time/ZOH/z⁻¹, PX4 rate controller 구조 (250Hz), 이산 PI vs 연속 PI.
- 실습: UnitDelay/DiscreteIntegrator 사용 (ex4), 1축 → 3축 rate 폐루프.
- 과제: Ts 를 키워 성능 저하 관찰 + rate 게인 튜닝.
- 평가: 채점기 + Ts 영향 리포트.

**10주. Control II + Allocation — 호버 폐루프 완성**
- 목표: 캐스케이드(rate→attitude→position)와 믹서. **드론이 처음 뜨는 주.**
- 이론: 쿼터니언 자세오차(개념), 캐스케이드가 계층인 이유, Quad-X 믹서.
- 실습: Attitude/Position Controller + Mixer 블록 연결 → 호버 미션 PASS.
- 과제(팀 프로젝트 시작): 호버 다이어그램 완성 + 스텝 외란 리젝션 튜닝.
- 평가: 채점기(호버 판정: 고도 오차/자세 수렴 자동 검사).

### 파트 5 — 센서와 추정 (Sensors → Estimation) ★교육 하이라이트★

**11주. Sensors 팔레트 — ideal → noisy 의 순간**
- 목표: 완벽한 센서라는 거짓말. 노이즈 모델(bias, noise density, 샘플레이트).
- 이론: 실제 IMU datasheet 읽기 (ICM-42688 급), 바이어스/백색잡음/샘플링.
- 실습: **10주차 호버 다이어그램 그대로, IMU 블록의 fidelity 드롭다운만
  ideal→noisy 로 전환 → 기체가 흔들리기 시작하는 것을 목격.**
  이 한 번의 클릭이 상태추정이라는 분야가 존재하는 이유다.
- 과제: 노이즈 파라미터 스윕 → 어느 수준부터 임무 실패하는지 경계 찾기 (시드 고정).
- 평가: 채점기 + 경계 리포트.

**12주. Estimation 팔레트 — 필터로 복구**
- 목표: 상보필터의 원리 (자이로 적분 + 가속도계 보정).
- 이론: 왜 자이로만으로는 드리프트하고 가속도계만으로는 떨리는가 → 융합.
- 실습: Complementary Filter 블록 삽입 → 11주차의 흔들림 복구.
  (심화: EKF 블록 맛보기 — MATLAB 라인 T1 수업의 예고편)
- 과제: 필터 게인 튜닝 → 복구 성능 vs 응답 지연 트레이드오프 리포트.
- 평가: 채점기(추정 RMS 자동 판정).

### 파트 6 — 항법·실기체 인터페이스·종합 (Navigation → Interfaces)

**13주. Navigation — 미션을 시키는 법 + 실시간 모드**
- 목표: waypoint/go-to-goal 유도. 시뮬 시간 vs 벽시계 시간.
- 이론: 위치 오차 → 속도 명령(P 유도), 실시간 모드(벽시계 페이싱, 지터).
- 실습: go-to-goal 제어기 + "실시간" 체크 → Scope 가 벽시계로 흐르는 것 관찰.
  ROS2 turtlesim 데모 (ex6): 같은 다이어그램 구조가 실제 미들웨어로.
- 과제(팀): waypoint 2~3개 순회 미션.
- 평가: 채점기(도달 판정) + 미션 데모.

**14주. Interfaces — 플랜트를 진짜로 바꾼다**
- 목표: fidelity Level 2 (Gazebo). "다이어그램은 하나" 컨셉의 완성.
- 이론: 시뮬레이터 브리지, 시간 동기, SITL 개념.
- 실습: Plant 블록 ↔ Gazebo Bridge 맞교체 (포트 호환) — 같은 제어기가
  Gazebo 기체를 난다. ROS2 Pub/Sub 로 토픽 확인.
- 과제(팀): 종합 프로젝트 마무리 (13주 미션을 Gazebo 에서 재현).
- 평가: 팀 진도 점검.
- ※의존: [P44b] Gazebo Bridge — 미구현 시 이 주는 ROS2 실기체(터틀봇/드론
  텔레메트리) 데모로 대체 가능.

**15주. HILS 시연 + 프로젝트 발표**
- 목표: 자기 다이어그램을 설명하는 능력. fidelity Level 3 예고.
- 실습: 팀 발표 (다이어그램 화면 + 파형 해설 + 튜닝 근거).
- 데모: 강사가 같은 다이어그램을 실기체/HILS 로 — "학기 초의 그 그림이
  진짜 기체를 난다" (P41/P43, 심화 과정 상품 예고).
- 평가: 프로젝트 60% (채점기 40 + 발표 20), 주차 과제 40%.
