      함수형(권장): def f(t, a, b): … return x, y —
      입력 포트 = t 를 제외한 인자(이름이 포트 라벨),
      출력 포트 = return 항 수. 저장하면 n_in/n_out 이 자동 설정된다.
      여러 def 를 쓰면 마지막이 블록 함수(위는 헬퍼).

      식/문장형: 입력 u0..u{n_in-1}, 출력
      y 또는 y0.. 대입.
      공통으로 t, math 함수(sin cos atan2
      sqrt pi …), abs/min/max 사용 가능.
