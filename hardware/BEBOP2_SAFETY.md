# Bebop 2 실내 비행 안전 체크리스트 ([CLD-P41] 선행 조건)

비행 전 전부 체크. 하나라도 빠지면 비행하지 않는다.
이 체크리스트 자체가 커리큘럼 자료가 된다 (실기체 모듈 1교시).

## 기체
- [ ] 프로펠러 가드 장착
- [ ] 프로펠러 4개 균열/변형 없음, 단단히 고정
- [ ] 배터리 ≥ 50% (스파이크 기준; 30% 미만이면 스크립트가 스스로 중단)
- [ ] 배터리 외관 부풀음 없음 (단종 기체 — 구형 배터리 주의)
- [ ] 펌웨어 최신 (FreeFlight 앱으로 확인, 최초 1회)

## 공간
- [ ] 실내 최소 4m × 4m × 2.5m, 장애물·사람·반려동물 없음
- [ ] 바닥에 이착륙 매트 (호버 고도 ~1m)
- [ ] 천장 조명/팬과 거리 확보
- [ ] 창문 닫힘 (기류), 야외 비행은 이 스파이크 범위 아님

## 통신/소프트웨어
- [ ] PC 가 Bebop2-xxxxxx WiFi 에 연결됨 (인터넷 아님!)
- [ ] `--dry-run` 이 먼저 통과
- [ ] 시뮬레이션 모드에서 같은 다이어그램 검증 완료 (P43 부터 적용)
- [ ] E-stop 숙지: **Ctrl+C = 즉시 착륙** (스크립트에 구현됨)
- [ ] 보조자 1인 (조종 PC 담당과 기체 관찰 분리 권장)

## 비행 중 중단 조건
- 기체가 시야에서 벗어남 / 예상 밖 드리프트 1m 이상 / 이상음
- 텔레메트리 5초 이상 끊김
- 배터리 경고

## 사고 시
- 즉시 Ctrl+C → 안 되면 기체 뒤집기(모터 자동 정지) → 배터리 분리
